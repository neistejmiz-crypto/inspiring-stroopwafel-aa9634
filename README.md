# Новая философия образования — interactive web lecture

Russian-language interactive lecture and workshop for anyone interested in the future of education, with practical activities and optional background music.

**Stack:** React 19, Vite, Tailwind CSS v4, TypeScript, hosted on Netlify (static, `dist`).

## Run locally
```sh
npm install
npm run dev
```

## Media
